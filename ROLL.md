# ROLL.md

> File tương thích theo tên yêu cầu ban đầu. Nguồn định nghĩa vai trò chính thức nằm tại `ROLES.md`.

## Quy tắc

Mọi Agent phải đọc `ROLES.md` để xác định role, responsibility, output và QA ownership trước khi bắt đầu task.

Các role hiện tại:

- Orchestrator / Lead Architect
- Business Analyst Agent
- Information Architecture Agent
- UX Agent
- UI / Design Agent
- Content Architect Agent
- Module Planner Agent
- Backend Agent
- Admin/CMS Agent
- Frontend Renderer Agent
- QA Agent
- Security Agent
- SEO/Performance Agent

Không tự tạo role mới có quyền vượt `RULES.md`, `AGENTS.md` hoặc `DEFINITION_OF_DONE.md`.
