# I18N.md

## Goal

Hỗ trợ song ngữ/đa ngôn ngữ mà không duplicate tùy tiện toàn bộ entity.

## Model

Phân tách:

- non-localized base fields;
- localized translation fields.

Ví dụ Page:

```text
Page base
  id
  site_id
  template
  status

PageTranslation
  page_id
  locale
  title
  slug
  seo
```

Dynamic content field definition cần flag `localized`.

## Required Capabilities

- default locale;
- enabled locales;
- fallback locale;
- translation status;
- localized slug;
- localized menu;
- localized SEO;
- hreflang;
- locale-aware content source.

## URL Strategy

Chốt bằng ADR, ví dụ:

```text
/vi/...
/en/...
```

hoặc default locale không prefix. Strategy phải nhất quán và SEO-safe.

## Constraints

Slug uniqueness phải theo site + locale + path scope phù hợp.
