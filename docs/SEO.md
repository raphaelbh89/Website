# SEO.md

## SEO Engine Scope

SEO là domain feature, không chỉ vài meta tags.

## Per Page / Content

- title;
- description;
- canonical;
- robots directives;
- OpenGraph;
- social image;
- structured data;
- slug;
- redirects khi slug đổi.

## Site-Level

- robots.txt;
- sitemap.xml / sitemap index;
- organization/site schema;
- default social metadata;
- verification/integration settings.

## Structured Data

Tùy content type:

- Organization;
- LocalBusiness/School nếu phù hợp;
- Article/NewsArticle;
- BreadcrumbList;
- Course khi đúng ngữ nghĩa;
- FAQPage chỉ khi nội dung thực tế phù hợp.

Không spam schema không đúng nội dung.

## Multilingual

- localized URLs;
- hreflang;
- canonical per locale;
- translated metadata;
- fallback rules.

## Technical SEO

- semantic HTML;
- clean status codes;
- 404;
- 301 redirects;
- pagination strategy;
- image alt;
- internal linking;
- crawl-safe filter/query handling.

## Performance

SEO review bao gồm Core Web Vitals considerations: images, fonts, JS, cache, rendering strategy.
